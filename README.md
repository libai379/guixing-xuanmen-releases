# 癸星玄门

命理排盘 App：八字、紫微、六爻、奇门、太乙、风水、大小六壬都在手机上本地计算，可以接 AI 分析。

本仓库只放安装包，不含源码。下载见 [Releases](https://github.com/libai379/guixing-xuanmen-releases/releases)；App 内「设置 → 关于 · 检查更新」会自动从这里取新版。

## 致敬荀爽老师

癸星玄门的根在星阙。谨向**荀爽老师**（Herakleios，爽哥，[B 站主页](https://space.bilibili.com/16869601)）致敬。

- **星阙这套体系**：最早的星阙 Horosa 由**郑大哥**一手创建，荀爽老师参与辅助设计，并把相关 App 与 Web 公开出来，后来者才有得研究、学习与延展。
- **公开讲授的知识**：App 的 AI 知识库收录了荀爽老师 B 站往期直播整理出的六爻、占星、易经讲稿，和八字、斗数、六爻笔记。

没有两位老师搭起的星阙体系和公开分享的精神，就没有这个 App。

（星阙的源流，出自桌面版 README 的致谢段：[README_ZH.md](https://github.com/Horace-Maxwell/Horosa-Web-App-comprehensively-improved-Windows/blob/main/README_ZH.md)。）

## 来源

**排盘计算：星阙桌面版**

七个系统的计算逻辑，提取自 [Horace-Maxwell/Horosa-Web-App-comprehensively-improved-Windows](https://github.com/Horace-Maxwell/Horosa-Web-App-comprehensively-improved-Windows)（在旧星阙基础上改良的桌面版，v3.9.3 至 v3.10.0，许可证 AGPL-3.0），再移植成 Dart，让手机不联网也能算。验收的判准是桌面版「AI导出」的原文。感谢 Horace Maxwell 的整理与改良。

**太乙排盘：kintaiyi**

太乙的排盘部分直译自 [kentang2017/kintaiyi](https://github.com/kentang2017/kintaiyi)（MIT）。星阙桌面版也接入了 kentang2017 公开的多个术数项目。

**AI 知识库**

- [Horace-Maxwell/divination-notes-prompt](https://github.com/Horace-Maxwell/divination-notes-prompt)：荀爽老师 B 站往期直播与星阙公众号文章的整理。
- 星阙桌面版的帮助文档。
- 网上转录的奇门、风水古籍资料（二手来源，不是校勘本）。

**历法与天文**

[lunar](https://pub.dev/packages/lunar)（6tail，MIT）、[astronomia](https://pub.dev/packages/astronomia)（MIT）。

## 这个 App 是什么、不是什么

癸星玄门是个人做的手机移植，**不是星阙官方出品**，也没有得到郑大哥、荀爽老师或 Horace Maxwell 的认可或背书。用它遇到的问题，请到本仓库的 [Issues](https://github.com/libai379/guixing-xuanmen-releases/issues) 反馈，不要去打扰他们。
